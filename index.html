Google 雲端同步設定

系統會自動解析網址並掃描裡面的 `.pdf` 與 `.epub` 檔案。

  1. 造訪 Google Cloud Console 並建立新專案。
  2. 前往「API 和服務」>「庫」，搜尋並啟用 Google Drive API。
  3. 前往「OAuth 同意畫面」，選擇 External (外部)，輸入應用程式名稱與 Email 並儲存。
  4. 前往「憑證」>「建立憑證」> 選擇 OAuth 用戶端 ID。
  5. 應用程式類型選擇 Web 應用程式。
  6. 在「已授權的 JavaScript 來源」填入您開啟此網頁的 Domain（例如 `http://localhost` 或 `https://yourdomain.com`）。
  7. 複製產生的 Client ID 並貼入上方欄位即可！
